## 内容与证据原则

正文为原创概述，资料包括条约和档案、当事人记述、国际机构与政府文件、大学及学术研究。官方文件用于辨识政策和立场，不直接代替独立评价；公开页面只有摘要或书介时，在来源说明中明确标注。没有复制维基百科正文或整篇受版权保护的文献。

既写建设、改革、抵抗和生活改善，也记录侵略、镇压、饥荒、强制与歧视。有充分证据的暴行无需与否认说法机械平分篇幅。人物评价按具体事件区分成果、选择、责任和证据限制，避免用单一褒贬标签替代传记。

伤亡存在统计争议时保留范围、口径和不确定性，不制作无来源的精确数字。1938 年水灾图使用研究所引受调查灾区县耕地受淹比例，不能解释为全省或今日疆界的比例。2025 年人口图注明国家统计局地域范围及 2026 年发布时点。超额死亡、少出生人口、医院报告和全部死亡不能混用。

2026 年当代条目使用截至截点的资料。2025 年统计、2026 年预测与 2030/2060 年目标分开表述；未结束的 2026 年不填写完整年度结果。生卒年不明者明确说明；陈仪与陈毅区分，不将台湾行政长官误作同名近似人物。

## 交互与架构

继续使用 Node 原生静态构建，无新增 npm 运行依赖。构建新增 197 个杂项路由，全站合计 204 个 HTML 页面。中英文首页都增加杂项导航，原个人资料、论文和站点统计模块继续使用。

文章正文、来源、人物行动、图谱初始状态均在 HTML 中。检索和图谱控件通过渐进增强启用；无 JavaScript 时目录、文章、引用和人物图仍可读。只有图谱页面请求精简的本站 JSON 数据；普通文章无需加载全部历史正文或远程接口。

人物—事件连线仅来自 `event.actors` 中的显式行动记录。共同参与可能是合作或对抗，不绘制未经证实的私人关系，不以节点位置、距离或数量表达影响力。节点链接到对应正文，人物页和图谱显示同一组行动记录，避免人工维护两套事实。

每个事件有时序图；12 个事件另有机制对照表或有来源的数值条形图。数值、单位和局限以文字同时呈现，读者无需从颜色或图形猜测数据。

资源使用内容哈希命名，支持 `BASE_PATH`。正文有独立 canonical、元描述和 Article 结构化数据，所有新页面进入 sitemap。脚本、字体和图形本地加载；访客计数沿用同域名 Busuanzi 服务端累计值，原 127 UV / 170 PV 仅作迁移记录，不额外叠加或硬编码。

## 验证记录

自动校验使用 Node 原生测试与站点输出检查，覆盖内容完整性、关联、引用、图谱边线真实性、Unicode 组合检索、未知卒年、静态输出、总目与原主页兼容。浏览器验收使用缓存中的 `@playwright/cli@0.1.22`、已安装 Chrome 和 axe-core，不增加项目依赖。

真实浏览器回归覆盖 19 种页面、1440 / 1024 / 768 / 390 / 320 像素五种宽度，共 95 项布局检查；另测组合筛选、URL 恢复、重置、无结果、人物搜索、图谱选择和后退、引文锚点、手机菜单与 Escape。无 JavaScript 的事件索引、人物索引、1989 年条目和毛泽东传记检查全文、来源与溢出情况。

首轮检查发现并修复筛选重置的浏览器默认行为时序问题；改为明确清空控件后立即应用筛选。无障碍检查发现的方法页链接点击区域不足和图表脚注链接样式不足也已修正。桌面导航隐藏无用途的手机菜单按钮。打印样式检查保留来源与表格、隐藏站点导航，没有横向溢出。
